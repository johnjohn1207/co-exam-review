# CO3020 計算機組織：互動式動態題庫與轉譯實驗室 (Computer Organization Review)

> 專為國立中央大學 / 國立東華大學通訊與資工領域「計算機組織 (CO3020)」設計的互動式學習平台。完整整合 Chapter 1、2、3 講義投影片核心觀念、作業一與作業二全真解析、動態參數計算題求解器與 18 大 C/MIPS 雙向轉譯特訓中心。

📱 **手機／線上即時體驗網址**：[https://johnjohn1207.github.io/co-exam-review/](https://johnjohn1207.github.io/co-exam-review/)

## 🌟 核心功能特色

1. **動態計算題庫與即時驗證引擎 (Dynamic Calculation Arena)**：
   - 涵蓋 Chapter 1（CPU 效能方程式、加權 CPI、阿姆達爾定律、功耗牆、製程微縮）、Chapter 2（R/I-type 機器碼編碼、PC-relative 分支偏移量、Pseudo-Direct 跳躍目標位址、迴圈動態指令計數、跨步陣列偏移量）與 Chapter 3（32 位元有號數溢位判定、ALU 控制訊號解碼、布斯乘法演算法週期追蹤、帶符號除法商數/餘數判定、IEEE 754 浮點數十六進位機器碼互轉、浮點數加法四步驟正規化）。
   - 支援**無限制隨機變更數值**（點擊「🎲 換一題」）。
   - 內建高精度數值求解器，支援浮點數、十六進位碼（如 `0x8C220004`）、狀態字串（`overflow`, `AND`, `SLT` 等），自動容錯並即時回饋正誤。
   - 答錯時**自動展開步驟式推導詳解**，完整呈現每一步代入過程。

2. **C / MIPS 雙向轉譯特訓中心 (18 大高頻考題矩陣)**：
   - 支援兩種學習模式：
     - 👁️ **對照研讀模式**：並列呈現 C 與 MIPS 程式碼、逐行對應硬體剖析表 (Line-by-Line Breakdown) 與考試陷阱預警。
     - 🧠 **盲測默寫特訓模式**：遮蔽目標程式碼，提供即時默寫輸入區、關鍵提示摺疊展開與核對解答功能。
   - 收錄 18 道高頻必考題型：
     - 算術運算與陣列常數偏移量
     - 分支反轉與不等式比較
     - 複合邏輯條件（`&&`, `||` 捷徑求值）
     - While / For 陣列巡覽
     - 🔥 **作業一 Q7 必考真題**：帶步進計數器迴圈逆向還原
     - 🔥 **作業一 Q8 必考真題**：記憶體指標步進累加迴圈逆向還原
     - 🔥 **作業一 Q9 必考真題**：二重巢狀跨步乘法迴圈 ($D[4j] \implies 16j$)
     - Switch-Case 分支跳躍表（Jump Table）
     - 陣列走訪與極值搜尋條件更新
     - 葉程序（Leaf Procedure）堆疊備份還原
     - 指標巡覽 vs 陣列索引效能最佳化
     - 字串複製函式（`strcpy`）與位元組指標
     - 遞迴階乘函式（`fact`）與 `$ra` 保護
     - 🌟 **作業二核心真題**：雙遞迴費氏數列（Recursive Fibonacci）與堆疊訊框保護
     - 氣泡排序（`sort` / `swap`）非葉程序與巢狀暫存器保護

3. **作業實戰全真解析專區 (Assignments Lab)**：
   - **Assignment 1 必考解析**：完整整理 Q1 至 Q9 核心公式、題型精華、易錯陷阱與考題對應。
   - **Assignment 2 遞迴費氏數列全指南**：
     - 規格規範、輸入邊界檢驗（$0 \le n \le 20$）
     - 雙遞迴堆疊訊框（Stack Frame Layout）架構圖解（`$ra`, `$s0`, `$a0` 偏移量）
     - $F(3)$ 呼叫樹與堆疊深層追蹤表
     - 完整 MARS 可組譯執行原始碼範本
     - 3-10 分鐘英文口說錄影展示評分標準與要點

4. **重點精華與公式速查手冊 (Formula Cheat Sheet)**：
   - 完整收錄 Chapter 1、Chapter 2 與 Chapter 3 知識樹與所有關鍵公式，支援 KaTeX 數學公式即時渲染。

5. **全真模擬隨機測驗模式 (Mock Exam Arena)**：
   - 隨機自全章節題庫抽取 5 道計算題並動態產生全新隨機數值，支援即時自動批改、百分制結算與錯題檢討。
