## 一、 背景規格與圖表對照

### 1. 16 位元半精度浮點數格式（習題 3.27）
* **總位元數**：16 bits
* **符號位元（Sign, S）**：1 bit（最左側）
* **指數欄位（Exponent, E）**：5 bits，偏移量（Bias）為 15（即 Excess-15，$E = \text{真實指數} + 15$）
* **假數 / 有效數欄位（Fraction / Significand, F）**：10 bits（規格化數值隱含前導 1，即 $1.F$）
* **捨入機制**：保留保護位元（Guard bit, G）、捨入位元（Round bit, R）與黏滯位元（Sticky bit, S），依據「向最近偶數捨入」（Round to nearest even）規則裁決。

### 2. 硬體架構對照
* **圖 3.3（Figure 3.3）**：第一版乘法硬體（被乘數暫存器向左位移、乘數暫存器向右位移）。
* **圖 3.5（Figure 3.5）**：最佳化乘法硬體（乘積暫存器整組向右位移，被乘數固定長度）。
* **圖 3.6（Figure 3.6）**：乘法演算法追蹤表格式。
* **圖 3.8 / 3.10（Figure 3.8 / 3.10）**：第一版除法硬體與執行追蹤表格式。

## 四、 習題 3.18 詳解

### 1. 題目描述
使用圖 3.10 表格格式，運用圖 3.8 第一版除法器硬體架構，計算 74 除以 21。

### 2. 數值情境分析
* **情境 A（八進位數值解讀，承襲前題脈絡）**：
  前兩題均為八進位數值。若此處 74 與 21 為八進位：
  * 被除數：$74_8 = 60_{10} = 111100_2$（6 位元無號整數，滿足 $\le 63$）。
  * 除數：$21_8 = 17_{10} = 010001_2$（6 位元無號整數）。
  * 運算結果：$60 \div 17 = 3$ 餘 $9$。
* **情境 B（純十進位解讀）**：
  若為十進位 74 與 21：
  * 被除數：$74_{10} = 1001010_2$（需 7 位元表示）。
  * 除數：$21_{10} = 0010101_2$。
  * 運算結果：$74 \div 21 = 3$ 餘 $11$。

### 3. 步驟追蹤表：情境 A（八進位 $74_8 \div 21_8 = 60 \div 17$）
* 暫存器寬度：除數暫存器 12 位元（初始於左半部），餘數暫存器 12 位元（初始置於右半部），商數暫存器 6 位元。共執行 7 輪（$n+1$ 輪）。

## 五、 習題 3.29 詳解

### 1. 題目描述
手算 $2.6125 \times 10^1 + 4.150390625 \times 10^{-1}$，格式為 16 位元半精度（習題 3.27），保留 1 個 Guard、1 個 Round、1 個 Sticky 位元，向最近偶數捨入。

### 2. 數值轉換
1. **數值 A**：$2.6125 \times 10^1 = 26.125_{10}$
   * $26 = 11010_2$
   * $0.125 = 0.001_2$
   * 二進位科學記號：$+1.1010001000_2 \times 2^4$
   * 偏置指數：$E = 4 + 15 = 19 = 10011_2$
   * 假數欄位（10 bits）：`1010001000`
2. **數值 B**：$4.150390625 \times 10^{-1} = 0.4150390625_{10}$
   * $0.4150390625 \times 1024 = 425$
   * $425 = 256 + 128 + 32 + 8 + 1 = 110101001_2$
   * 二進位科學記號：$+1.1010100100_2 \times 2^{-2}$
   * 偏置指數：$E = -2 + 15 = 13 = 01101_2$
   * 假數欄位（10 bits）：`1010100100`

### 3. 計算步驟
* **步驟 1：對齊指數**
  指數差為 $4 - (-2) = 6$。將數值 B 向右位移 6 位元：
  * 原假數：`1.1010100100`
  * 右移 6 位元後：`0.0000011010`，溢出位元為 `1 0 0 1 0 0`
  * Guard 位元（第 1 位溢出）：`1`
  * Round 位元（第 2 位溢出）：`0`
  * Sticky 位元（後續位元 OR）：`1`（因包含 `1 0 0`）
  * 對齊後 B 之假數：`0.0000011010`，GRS = `1 0 1`
* **步驟 2：假數相加**
  ```text
    A:   1.1010001000  0 0 0
  + B:   0.0000011010  1 0 1
  --------------------------
  和值:   1.1010100010  1 0 1
  ```
* **步驟 3：規格化與捨入**
  * 和值最高位為 1，無需規格化位移，指數維持 $2^4$（$E = 19$）。
  * 捨入判定：GRS 為 `1 0 1`，嚴格大於 $0.5\text{ ULP}$，執行進位（Round Up）。
  * 捨入後假數：`1.1010100010` $+ 1\text{ LSB} =$ `1.1010100011`。

### 4. 最終答案
* **16 位元浮點數格式**：`0 10011 1010100011`（十六進位 `0x4EA3`）。
* **十進位數值**：
  $$1.1010100011_2 \times 2^4 = 11010.100011_2 = 26 + \frac{1}{2} + \frac{1}{32} + \frac{1}{64} = 26.546875$$

## 六、 習題 3.35 詳解

### 1. 題目描述
手算 $(A \times B) \times C$，其中：
* $A = 3.41796875 \times 10^{-3}$
* $B = 6.34765625 \times 10^{-3}$
* $C = 1.05625 \times 10^2$

### 2. 數值二進位表示
* $A = 1.75 \times 2^{-9} = +1.1100000000_2 \times 2^{-9}$（$E = 6$）
* $B = 1.625 \times 2^{-8} = +1.1010000000_2 \times 2^{-8}$（$E = 7$）
* $C = 1.650390625 \times 2^6 = +1.1010011010_2 \times 2^6$（$E = 21$）

### 3. 第一步：計算 $(A \times B)$
* 指數相加：$(-9) + (-8) = -17$。
* 假數相乘：$1.11_2 \times 1.101_2 = 1.75 \times 1.625 = 2.84375 = 10.11011_2$。
* 規格化右移 1 位元：$1.0110110000_2 \times 2^1$，指數調整為 $-17 + 1 = -16$。
* **下溢判定（Underflow）**：
  16 位元半精度規格化數之最小指數為 $E=1 \implies \text{真實指數} = 1 - 15 = -14$。
  計算所得之指數 $-16 < -14$，發生**指數下溢（Underflow）**。
  在標準硬體實作下（Flush to Zero），下溢截斷為 $0$。

### 4. 第二步：乘以 $C$
* $(A \times B) \times C = 0 \times C = 0$。

### 5. 最終答案
* **16 位元浮點數格式**：`0 00000 0000000000`（十六進位 `0x0000`）。
* **十進位數值**：$0$。
*(註：若系統支援非規格化數 Subnormal，其值經兩次位移截斷後十進位約為 $2.29164 \times 10^{-3}$，與 3.36 答案依然不同)*。

## 七、 習題 3.36 詳解

### 1. 題目描述
手算 $A \times (B \times C)$。

### 2. 第一步：計算 $(B \times C)$
* 指數相加：$(-8) + 6 = -2$。
* 假數相乘：$1.625 \times 1.650390625 = 2.681884765625 = 10.101011101001_2$。
* 規格化右移 1 位元：
  * 假數：`1.0101011101`，溢出位元為 `0 0 1`
  * 指數調整：$-2 + 1 = -1$（偏置指數 $E = -1 + 15 = 14 = 01110_2$）
  * GRS 位元：$G = 0, R = 0, S = 1$
  * 向最近偶數捨入：因 $G = 0$，捨去不進位（Round Down）。
  * 捨入後假數：`1.0101011101`。

### 3. 第二步：計算 $A \times (B \times C)$
* 指數相加：$(-9) + (-1) = -10$。
* 假數相乘：
  * $A$ 假數：$1.11_2 = 1.75$
  * $(B \times C)$ 假數：$1.0101011101_2 = \frac{1373}{1024}$
  * 乘積：$1.75 \times \frac{1373}{1024} = \frac{9611}{4096} = 2.346435546875 = 10.010110001011_2$。
* 規格化右移 1 位元：
  * 假數：`1.0010110001`，溢出位元為 `0 1 1`
  * 指數調整：$-10 + 1 = -9$（偏置指數 $E = -9 + 15 = 6 = 00110_2$）
  * GRS 位元：$G = 0, R = 1, S = 1$
  * 向最近偶數捨入：因 $G = 0$，捨去不進位（Round Down）。
  * 捨入後假數欄位（10 bits）：`0010110001`。

### 4. 最終答案
* **16 位元浮點數格式**：`0 00110 0010110001`（十六進位 `0x18B1`）。
* **十進位數值**：
  $$(1 + \frac{177}{1024}) \times 2^{-9} = \frac{1201}{524288} \approx 0.0022907257 \quad (2.2907 \times 10^{-3})$$

## 八、 習題 3.37 詳解

### 1. 題目描述
根據 3.35 與 3.36 之答案，等式 $(A \times B) \times C = A \times (B \times C)$ 是否成立？

### 2. 答案
**不成立（Does NOT hold）**。

### 3. 架構與原理分析
1. **核心原則**：電腦中的浮點數運算**不滿足結合律（Floating-point arithmetic is not associative）**。
2. **根因拆解**：
   * 在 3.35 中，優先執行極小數相乘 $(A \times B)$，導致指數降至 $-16$，低於 16 位元半精度硬體所能表示的最小規格化指數上限（$-14$），引發**指數下溢（Underflow）**，數值歸零，導致後續乘法結果為 $0$。
   * 在 3.36 中，先將較小數與較大數相乘 $(B \times C)$，中間指數維持在 $-1$，再乘以 $A$ 時指數為 $-9$，全程皆在規格化數的表示範圍內，成功保留有效位數，得到精確結果 $2.2907 \times 10^{-3}$。
